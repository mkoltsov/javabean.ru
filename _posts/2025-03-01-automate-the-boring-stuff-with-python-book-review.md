<p>Needed a book to brush up my Python skills in a quick and possibly fun way</p>

<p>Definitely, that was the right choice to make. This book checks every checkbox </p>

<p>Although I found it unneccessarily verbose in some areas, it still is the best Python book I've every read.</p>

<p> What I didn't like about it:</p>
<ol>
<li>Too much coverage of basic libraries that AI can help you with in no time</li>
<li>Excessive code listings, I'd prefer leaving the boilerplate aside and be able to find it on Github if needed</li>
</ol>

<p>Score 5/5</p>
